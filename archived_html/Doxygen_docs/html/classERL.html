Detailed Description

Container class for all submodules.

The ERL class acts as a central container or manager for the key components involved in the system, including the parser, preprocessor, encoder, decoder, and word bank. This design promotes modularity and simplifies interaction between the submodules.

Each public member corresponds to a core module in the data processing pipeline:

  • parser_ par handles input parsing.
  • preprocessor_ pre performs data preprocessing tasks.
  • encoder_ enc manages encoding logic.
  • decoder_ dec is responsible for decoding operations.
  • wordbank_ wb stores and retrieves word data.

The class currently does not encapsulate behavior (i.e., no methods), but it serves as a structural and logical grouping of submodules.
